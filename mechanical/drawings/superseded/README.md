# Superseded drawings

These were drawn **before the machine was measured**, against a premise that
turned out to be wrong: a 14.5″ kiosk door set inside a 19″ opening, with a fixed
frame spanning an **open card cage**.

The real 3280 has a **louvered outer door ~24.3″ wide** covering the whole cabinet
face, with a **perforated inner panel** behind it — no open cage. See
[`../../me1-findings.md`](../../me1-findings.md).

Kept for provenance only. **Do not build from these.** The current set lives one
directory up and is generated by
[`../make-drawings.py`](../make-drawings.py).
